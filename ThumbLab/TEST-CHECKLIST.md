# Thumb Lab: tester's checklist

Tick items off as you try them. The same list is in the app under **Test checklist**, where ticks are remembered.
135 things to check.


## Getting started

- [ ] App opens to the Projects page with no errors; the left bar has Projects, Library, Tester and Settings
- [ ] Hover any icon: a short name appears after a moment
- [ ] New project: enter a title and pick a niche, and it appears as a card
- [ ] Open a project: tabs are Concepts, Canvas, Variants, Test, Library
- [ ] Rename a project's title and niche from the project header
- [ ] Delete a project (asks first) and it disappears, along with its files
- [ ] Close and reopen the app: projects, variants, ideas and settings are all still there

## Concepts (ideas before drawing)

- [ ] Type an idea and press Enter: a card is added at the top
- [ ] Edit an idea's text and notes: changes stick after switching tabs
- [ ] Change an idea's status (Idea / Sketching / Drawn / Rejected)
- [ ] "Sketch this" creates a blank sketch and opens the sketch pad
- [ ] The idea shows which version it was used in
- [ ] Delete an idea (asks first)

## Canvas: bringing art in

- [ ] Link files…: choose a .psd and it becomes a new version with a preview
- [ ] Link a .clip (Clip Studio) file: preview appears
- [ ] Link a .procreate file (copied to this PC): preview appears
- [ ] Link a PNG or JPG: preview appears
- [ ] Drop several files from Explorer onto the drop zone: each becomes a version
- [ ] Paste: copy a screenshot, then use Paste in the Canvas tab (or Ctrl+V)
- [ ] Linking the same file twice says it's already in the project
- [ ] A PSD saved without Maximize Compatibility still previews (with a note)
- [ ] Save the linked file in Photoshop / CSP: the preview here updates within a few seconds
- [ ] The open icon next to a linked file opens it in its program
- [ ] The refresh icon re-reads the file; the folder icon shows it in Explorer
- [ ] Folder: choose a folder and every thumbnail in it appears as a tile with a preview
- [ ] Folder tiles show PSD, CSP, Procreate and image files; a big folder fills in as you scroll
- [ ] Click a tile to add it as a version; it then shows a green check with its letter
- [ ] Filter by name, the eye-off icon (hide ones already added) and the Add N button work
- [ ] Include subfolders also shows art in folders inside it
- [ ] Save a new file into the folder and its tile appears within a few seconds
- [ ] "Add new files automatically" adds files saved afterwards (not old ones)
- [ ] The x stops watching the folder; the open icon shows it in Explorer

## Variants (A / B / C)

- [ ] Each new piece of art gets the next letter: A, B, C…
- [ ] Versions show side by side with their letter
- [ ] The size slider (small and large picture icons) resizes every thumbnail
- [ ] Click a version to select it: its large preview, notes and checklist appear on the right
- [ ] Star a version as your pick (only one can be starred)
- [ ] Move a version earlier / later with the arrows
- [ ] Rename a version; add a video title and notes for it
- [ ] Remove a version (asks first; original files aren't deleted)
- [ ] A non-16:9 image shows a "not 16:9" warning and black bars
- [ ] The picture-plus icon under the version saves it to the project's library
- [ ] The monitor icon on a card (hover it) jumps to the Test tab with that version

## Blur, grayscale and squint tests

- [ ] Blur (drop icon) blurs every thumbnail; a strength slider appears while it is on
- [ ] Grayscale (half-filled circle) removes colour from every thumbnail
- [ ] Squint (eye icon) softens detail and contrast, with or without Blur
- [ ] The three can be combined (e.g. Blur + Grayscale)
- [ ] Alt+B, Alt+G and Alt+S toggle the tests from the keyboard
- [ ] The tests also apply on the Test tab (the whole feed) and in the sketch pad
- [ ] The same settings are kept when you switch tabs or restart
- [ ] Tiny size + blur on all versions: you can tell which composition still reads

- [ ] Layouts switch between Home feed, Search results, Watch page sidebar and Phone
- [ ] Your thumbnail appears among other videos at the chosen position
- [ ] The sun / moon icon switches the page between dark and light
- [ ] The duration badge shows in the corner and can be turned off
- [ ] The # box moves your thumbnail; clicking another slot in the feed also moves it
- [ ] Version buttons (A, B, C) swap which one is in the feed; ← → keys cycle them
- [ ] "All" puts every version in the feed next to each other
- [ ] The flag icon (Mark mine) outlines yours so you can find it
- [ ] Shuffle (crossed arrows) gives a different set of surrounding videos and moves your thumbnail to a random position
- [ ] The list-icon box sets how many videos are on the page (e.g. 12 / 24 / 36 / 48 on the home feed); the options change per layout

- [ ] The fit / 1:1 icon switches between Fit to window and Real size

- [ ] Niche (the tag box on the Test toolbar, right after the buttons): click it and type straight away; Enter applies it and the surrounding titles change

- [ ] Blur / Grayscale / Squint apply to the whole page, including your thumbnail

- [ ] Test reports success (or a clear error if the key is wrong)

- [ ] The globe icon switches real videos and placeholders; the order box (Relevant / Most viewed / Newest) changes the results
- [ ] Hide Shorts (phone-off icon, on by default) removes videos of 3 minutes or less from the real feed, and the app searches further so the feed is still full
- [ ] Most viewed shows a calendar box: All time, Last 24 hours, Last month, Last 3 months, Last year, or Custom range (pick from and to dates)
- [ ] A time frame changes which real videos appear; with few matches the page shows fewer videos and never repeats one
- [ ] A yellow info icon appears at the end of the toolbar only when something needs attention; hover it to read why
- [ ] There is no text line under the toolbar
- [ ] Refresh (circular arrow) fetches fresh results; reopening within a day reuses the saved copy
- [ ] Removing the key (trash icon) goes back to placeholders

## Sketch pad: drawing

- [ ] New sketch (Canvas tab or a variant) opens the pad at the chosen size
- [ ] Pen draws a crisp line; pressing harder makes it wider
- [ ] Pressure brush: light pressure gives faint, thin paint; hard pressure gives dense, wider paint
- [ ] Eraser removes pixels; harder pressure makes it wider
- [ ] Pressure eraser: light pressure erases a little, hard pressure erases fully
- [ ] Sliders: size, opacity, softness, pressure → size, pressure → opacity, smoothing, pressure feel
- [ ] [ and ] change brush size; the brush ring on the canvas matches the size
- [ ] With a mouse (no pressure) every tool still works
- [ ] The pen's eraser end (if it has one) erases
- [ ] Eyedropper (I) picks a colour; Alt+click picks with any tool
- [ ] Colour well, swatches and recent colours work
- [ ] Ctrl+Z / Ctrl+Y undo and redo strokes (up to 40)
- [ ] Space+drag and middle-drag pan; mouse wheel zooms; the Fit and 100% icons in the top bar
- [ ] Mirror view flips the picture for checking; Guides shows thirds, margin and the time-stamp zone
- [ ] Ctrl+Shift+D shows a pen debug readout (type, pressure) at the bottom

- [ ] Undo/redo also reverses adding, deleting and reordering layers
